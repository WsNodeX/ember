Reverse-mode autograd, written in the language you already know. Zero dependencies.

Ember is a from-scratch automatic-differentiation engine and neural-network library: differentiable tensors, layers, activations, losses, an SGD optimizer and a data loader, built on the Python standard library alone — no NumPy, no pip install. Every operation's forward math and its backward rule sit next to each other in one file, so .backward() stops being magic.

A graph, walked backwards

Every tensor keeps the operation that produced it and the inputs it came from. backward() sorts the graph topologically, seeds the output gradient with one, and applies each rule in reverse — accumulating where branches meet.

Checked against finite differences

Each backward rule is verified numerically against central differences of the forward pass. If a gradient is wrong, a test fails; that is why the small numbers above can be trusted.

Read it in one sitting

No C extensions, no generated code, no layers of abstraction. The whole engine is plain Python files you can open in an editor and follow from Tensor to loss to update.

Run it locally

Ember needs nothing but a Python interpreter — there is no install step. The two example programs run the same code paths this page just exercised.

# no install step — the library is the source tree
git clone https://github.com/WsNodeX/ember && cd ember
python examples/fit_linear.py    # recover y = 3x + 2 by gradient descent
python examples/xor_mlp.py       # the network training in the panel above
python docs/demo_script.py       # exactly the file this page executed
